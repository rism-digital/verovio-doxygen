423  // Here we hold references to all different glyphs used so far,
424  // including any glyph for the same code but from different fonts.
425  // They will be added at the end of the file as <defs>.
426  // With multiple font support we need to keep track of:
427  // a) the glyph (to check if is has been already added)
428  // b) the id assigned to glyphs on the (that is has been consumed by the already rendered elements)
429  // To keep things as similar as possible to previous versions we generate ids with as uuuu-ss (where uuuu is the
430  // Smulf code for the glyph and ss the per-session suffix) for most of the cases (single font usage). When the same
431  // glyph has been used from several fonts we use uuuu-n-ss where n indicates the collision count.

433  public:
