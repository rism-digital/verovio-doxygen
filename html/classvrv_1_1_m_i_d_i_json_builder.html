Detailed Description

This class collects the events of a MIDI export and builds the MIDI JSON from them.

Doc::ExportMIDI() and GenerateMIDIFunctor add every event they write to the MIDI file here too, with the same track, tick, channel and values, and the ID of the note for note-on events. The events of a track are kept in the order of the MIDI file, so that an event can be found by its index. Finalize() builds the JSON once all events are collected. The structure is the one of @tonejs/midi (Midi.toJSON()) with the ID added to each note.
